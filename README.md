RCB vs CSK Data Analysis Project

Project Overview

This project analyzes and compares the performance of Royal Challengers Bengaluru (RCB) and Chennai Super Kings (CSK) using Python.

Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- Matplotlib

Visualizations

- Bar Chart
- Pie Chart
- Histogram
- Line Chart
- Scatter Plot
- Winning Percentage

Project Objectives

- Compare runs scored by RCB and CSK.
- Analyze team performance.
- Visualize match-wise runs.
- Understand data patterns using charts.

Conclusion

This project helped me understand data analysis and visualization using Python.
